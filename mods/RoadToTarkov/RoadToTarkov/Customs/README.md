# Customs

- `Customs.tscn`: the map scene. A thin wrapper like Vostok's own maps: `Map.gd`
  plus the generated `Content` plus Vostok's `World` and `Core`.
- `Build/`: generated by `tools/build_customs.sh` from `maps/customs/layout.json`
  (not committed; rebuild with the script).
