Is it safe?

Not a virus. Here's the proof.

Windows may show a blue SmartScreen box the first time you run Cleanstrike, and a few antivirus tools may flag it in the days after a fresh release. That's a false positive. Here is exactly why it happens — and why the app is safe.

"Unknown publisher"

Cleanstrike is a free, independent app without an expensive code-signing certificate. SmartScreen warns about any new, unsigned app until enough people have run it. The warning is about reputation, not about anything the app does.

Why antivirus pings it

It's one portable .exe that carries the whole .NET runtime inside it, unpacks to a temp folder on launch, then reads the Steam registry to find your game. Generic heuristics flag that self-extract-and-scan shape — the same reason many honest game tools get tagged. It's a guess from the file's shape, not a real detection of anything malicious.

Run it anyway

On the blue SmartScreen box, click More info, then Run anyway. You only do this once. As each release is downloaded more, the warning stops appearing for everyone.

Check for yourself

Cleanstrike is fully open source. Read every line on GitHub, build the identical .exe yourself, or drop the download on VirusTotal — you'll see only a couple of heuristic engines guess, never a named, agreed-upon threat.

The short version: an unsigned, self-contained Windows app that scans your drives to find a game looks, to an automated scanner, a lot like something it shouldn't — so it warns just in case. Nothing in Cleanstrike collects your data, touches your files outside the game, or talks to anything but GitHub for updates. Click More info → Run anyway and raid on.
