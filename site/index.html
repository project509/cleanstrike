Cleanstrike

A mod manager for Road to Vostok. Drop mods in, press Play.

Download for Windows

– downloads · latest release

Finds your game

Looks through every Steam library on its own. Or point it at the folder yourself.

Install by dragging

.csmod, .vmz, .zip and .pck. Badly packed mods are repaired on install.

Keeps the game working

Mods for other game versions are held back, broken ones are rolled back, and a crashing setup boots clean next time.

Load order and profiles

Reorder, switch mods on and off, keep different setups.

Settings in one place

Each mod's options in the app, not in files.

Undo in one click

Removing Cleanstrike puts the game back as it was.

Included mods

Available

Tarkov Looting

Search containers and bodies one item at a time. Items you haven't seen are silhouettes until you examine them. Weapons and magazines still work before you do.
